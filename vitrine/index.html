Inteligência operacional para colheita e transporte de grãos

Como organizar máquinas, caminhões, horários e recebimento para colher e transportar mais grãos, com menos ociosidade, menor custo e sem gargalos?

O AgroRitmo simula a operação do talhão à unidade de recebimento com eventos discretos (SimPy), identifica gargalos com evidências, compara cenários e otimiza recursos com OR-Tools. Esta página é uma demonstração pré-calculada: todos os números abaixo vêm de simulações reais do motor, executadas na geração da página.

⚠ Cenário sintético de exemplo — soja, 1.120 ha, 6 talhões, 3 colheitadeiras, 6 caminhões. Os parâmetros são ilustrativos: não são médias oficiais do setor nem dados de uma fazenda real. Para editar a operação e rodar novas simulações, use o aplicativo completo (instruções no fim da página).

Aplicativo completo

A versão interativa (configurar a operação, importar dados, rodar simulações, cenários, otimização e calibração) é um app Streamlit que precisa de um servidor Python permanente:

pip install -r requirements.txt   streamlit run app.py

Legenda de origem: MEDIDO nos eventos da simulação · CALCULADO por fórmula · INFORMADO pelo usuário · ESTIMADO por modelo aproximado. Sem calibração com observações reais, os resultados não representam uma fazenda específica.
